# One言語 (OneLang32_AI_C)

シンプルさを追求したプログラミング言語 **One言語** の C++ 実装です。
ソースファイルの拡張子は `.1`、コンパイラは `onec.exe` です。

## ビルド

```bash
g++ -std=c++11 -Wall -o onec.exe src/main.cpp src/lexer.cpp src/parser.cpp src/codegen.cpp
```

## 使い方

```bash
onec.exe hello.1
```

---

## 言語仕様

### Hello, World!

```
Hello, World!
```

```
Hello, World!
```

文字列をそのまま書くだけで出力されます。

---

### 変数

```
x = 10
y = 3.14
z = "こんにちは"
x
y
z
```

```
10
3.14
こんにちは
```

`変数名 = 値` で代入。変数名だけを書くと出力。

### 式の出力

```

= x + 5
x * 2 =
```

```
15

```

先頭または末尾に `=` をつけると式を評価して出力します。

### 標準入力

```
名前を入力してください
x:
x
```

```
名前を入力してください
（入力: Alice）
Alice
```

`変数名:` で標準入力を変数に代入します。

### 条件実行

```
x = 10
x = 10 -> ぴったり10です
x > 5  -> 5より大きい
x < 5  -> 5より小さい
x != 3 -> 3ではない
```

```
ぴったり10です
5より大きい
3ではない
```

`式 比較演算子 式 -> 本体` の形式。比較演算子は `=` `!=` `>` `<` `>=` `<=`。

ブロック形式（複数文）:

```
x = 10
x > 5 -> {
    5より大きい
    = x
}
```

```
5より大きい
10
```

else:

```
x = 3
x > 10 -> {
    大きい
} -> {
    小さいか等しい
}
```

```
小さいか等しい
```

### ループ

while 形式:

```
i = 0
i < 5 o {
    = i
    i = i + 1
}
ループ終了
```

```
0
1
2
3
4
ループ終了
```

for 形式（`init; cond; incr o { }`）:

```
i=0; i<5; i+=1 o {
    = i
}
```

```
0
1
2
3
4
```

### 関数

```
add(a, b) {
    <- a + b
}
= add(1, 2)
= add(10, 20)
```

```
3
30
```

`<-` で値を返します。条件分岐と組み合わせた例:

```
max(a, b) {
    a > b -> {
        <- a
    } -> {
        <- b
    }
}
= max(5, 3)
= max(2, 8)
```

```
5
8
```

再帰関数（階乗・フィボナッチ）:

```
fact(n) {
    n <= 1 -> {
        <- 1
    } -> {
        <- n * fact(n - 1)
    }
}
= fact(5)
= fact(10)

fib(n) {
    n <= 1 -> {
        <- n
    } -> {
        <- fib(n - 1) + fib(n - 2)
    }
}
= fib(10)
```

```
120
3628800
55
```

### リスト

```
a = [10, 20, 30]
= a[0]
= a[2]
= a.len
a[1] = 99
= a[1]
a.add(40)
= a.len
= a[3]
```

```
10
30
3
99
4
40
```

ループでリスト全体を出力:

```
a = [10, 20, 30]
i = 0; i < a.len; i += 1 o {
    = a[i]
}
```

```
10
20
30
```

### 文字列連結

```
name = "World"
= "Hello, " + name
greeting = "Good " + "morning"
greeting
= "Count: " + 42
```

```
Hello, World
Good morning
Count: 42
```

`+` で文字列・変数・数値を連結できます。

---

### ファイル書き込み

```
"hello world" > out.txt
out.txt < "hello world"
```

どちらも `out.txt` に `hello world` を上書き書き込みします。

変数の内容を書き込む:

```
msg = good morning
msg > out.txt
```

`out.txt` に `good morning` が書き込まれます。

### コメント

```

```

```
11
```
